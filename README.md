# 🧹 SQL Data Cleaning Project – World Layoffs Dataset

This project focuses on cleaning and transforming raw layoff data using SQL.  
The dataset contains company layoff information from different industries and countries.  
The goal of this project is to make the data accurate, consistent, and analysis-ready.

---

## 📌 Project Objectives

- Remove duplicate records
- Handle missing and null values
- Standardize inconsistent text values
- Convert data types properly
- Remove unnecessary rows and columns




## 🛠️ Tools & Technologies Used

- MySQL
- SQL Window Functions
- CTEs (Common Table Expressions)
- Joins
- Aggregate Functions
- Data Cleaning Techniques


## 📂 Dataset Information

The dataset contains:

- Company Name
- Industry
- Location
- Total Employees Laid Off
- Percentage Laid Off
- Date
- Funding Raised
- Company Stage
- Country
